## 1. 进游戏前 / 刚进游戏

### 1.1 性能与设置
- **内存**：最低 4G，推荐 6G，8G 可流畅毕业；服务端推荐 4G（>8 人建议 8G）。
- **Java**：普通版用 Java 8，**子版本必须 > 271**（否则加载崩溃）；**CleanroomLoader 版必须 Java 25**。
- **启动参数**：整合包页给了推荐参数（普通版一长串 CMS 参数，CRL 版只有 `-XX:+UseZGC -XX:+UseCompactObjectHeaders -XX:ReservedCodeCacheSize=500M -XX:-DontCompileHugeMethods`）。
- **客户端避坑（强烈建议开局就做）**：
  - 鼠标跳转/加速 → 装 **Raw Mouse Input**（MC1.12 不兼容原始输入）。
  - 背包界面卡顿、开关背包掉帧、崩溃 → **删除 Blur 模组**（核显杀手）。
  - 有些机械描述字太小看不清 → 设置 → 视频设置 → **各项 GUI 大小**里调。
  - 末地光影异常 → `config/betterendforge/client.toml` 里把相关项 `true` 改 `false`。

#### 认领区块 + 强加载（FTB Utilities）

- **归属模组**：**FTB 实用工具（FTB Utilities, [FTBU]）**（本包 1.12.2 版）。
- **操作步骤**：
  1. `Shift + E` 打开**原版背包**（不是旅行者背包）。
  2. 点背包**左上角的"认领区块"按钮**，弹出区块地图。
  3. **左键**点区块 = **认领**（圈地，别人不能拆/放）。
  4. **Shift + 左键**点区块 = **保持加载（强加载）**——**必须先认领**，之后你走远/离线该区块也继续运行。
  5. **右键**取消认领；**Shift + 右键**取消加载。可拖动批量操作。
  6. 界面里会显示"已认领 / 已加载 **数量 / 上限**"。
- **上限**（FTBU 默认，本包可能已调高）：
  - 认领上限 `ftbutilities.claims.max_chunks` 默认 **100**；
  - 强加载上限 `ftbutilities.chunkloader.max_chunks` 默认 **10**；
  - 不够用（有权限/作弊）可改：`/ranks set_permission player ftbutilities.claims.max_chunks <数量>` 与 `/ranks set_permission player ftbutilities.chunkloader.max_chunks <数量>`。
  - **1.17 起内置上限已提到 10000**，基本不用改。
- **其它**：FTBU 配置在 `./local/ftbu/config.json`（服务端）/ `./local/client/ftbutilities.cfg`（客户端），把 `B:journeymap_overlay=true` 打开可在**旅行地图**里显示区块声明。
- ⚠️ **强加载不加载实体**：**不要**把电动刷怪笼/自动化屠宰场强加载，否则会堆到几千实体（原话："想感受 3000+ 实体的高温吗"）。1.15 后偶发"强加载失效"bug → 加 Forged Carpet，用 `/player ID spawn` 假人加载。

### 1.5 开局装备：通量电钻（Fluxbore）

- **出处**：**热力革新（Thermal Innovation, [TI]）**，Team CoFH 出品、属"热力系列"，前置为热力基本 + CoFH 核心（整合包内为 [TI] 0.3.6，另有同模组的通量电锯、通量磁铁等）。
- **玩法**：RF 驱动的电动采掘工具，对**石质/土质方块**高效，是前期主力挖矿工具。
  - 支持镐类附魔：**效率 / 时运 / 精准 / 扩容**（时运与精准互斥；扩容 = 提升电池容量）。

  - 装**整合组件**可提升采掘等级（如达到钻石镐级/更高，具体以 JEI 为准）。
  - 有"**没电也能挖石头**"的特性，所以也有人把格子全给范围拓展、一次挖一大片。
- **充能**（需要 RF 红石通量）：
  1. **能量灌注机（Energetic Infuser）** —— 热力膨胀的标准物品充电机，放进去接电即可（1.12.2 首选）。
  2. **通量电容（Flux Capacitor）** —— 红石兵工厂的便携电源，随身给背包内物品充能。
  3. **通量网络（Flux Networks）** —— 建好后对快捷栏/背包物品**无线充能**（可跨维度）。
  4. 供电用 **斯特林/热力能源炉** 等 RF 发电机；热力机器的能量面要对准充能设备（用新月锤调方向）。
  5. ⚠️ 网上（新版本）教程里的"**工匠工作台**"是 **1.15+ 才有**的充能/改装台，1.12.2 没有——本包请用**能量灌注机**充能。

## 3. 前期发电与"跳赤石"路线

### 3.1 IC2 核电：虚空生电
- IC2 反应堆**具有虚空生电特性**：用 **MEK 线缆的"拉"模式**从每个面抽面板电量，**最多可抽 30 面**，发电量可观。
- 反应堆必须**紧贴核反应仓**；仓不能直接放。
- 燃料棒/加工燃料**有辐射**，需防护：全套量子/防化服，或龙研屏障项链硬顶。

### 3.2 三种经典堆（实测数据，1.x 版本）
| 堆型 | 材料要点 | 实测发电 |
| --- | --- | --- |
| **420 核电** | 元件热交换器×1、超频散热片×28、元件散热片×11、四联铀燃料棒×7 | ~97k RF（标称 420 EU，本包魔改成 2 倍=840 EU） |
| **青金石暴力强冷（铀）** | 反应堆冷却注入器（LZH，贴反应堆的那面**必须对准反应堆**）+ 青金石块 | ~963k RF |
| **青金石暴力强冷（MOX）** | 同上换 MOX；MOX **堆温越高发电越高** | ≈4.8M RF（可替代小光热） |

**自动化要点**：
- 燃料棒自动制作 → **ME 缓存指令器**（标目标数量 + 单次制作数量，缺料自动下单）。
- 反应堆自动换棒 → ME 接口标燃料棒、导管标**枯竭燃料棒**；**反应堆内不能留空位**（导管不认燃料棒位置，用**反应堆隔板**填满）。
- 强冷供青金石 → 反应堆冷却注入器内放青金石块，产物约 3 秒耗 1 块，务必保证青金石储备。
- **MOX 升温**：清空反应堆，先放 5–6 根燃料棒逐渐升温，再慢慢减量；青金石冷凝模块不会降温，担心爆堆可只压到 ~90%，照样可观。

### 3.3 跳赤石路线：跳过折磨的 IC2 反应堆
> 目的：不忍受慢吞吞的 IC2 反应堆（一根铀燃料棒要循环 ~5.5 小时才反应完），直接拿到**钚**。

1. 用**铱**（见 §2）做**强化铱板 → 工程控制电路 → 智能强冷裂变反应堆**，发电一上来就是 **15M RF/t**。
2. 它同时产出**钚** → 用钚做**分子重组仪**。
3. 记得在强冷堆的**数据接口**里改运行速度。

### 3.4 强冷燃料（青金石）自给
- **分子重组仪**：可把**蓝色羊毛 → 青金石块**（还能铱矿石/凛冰粉等），是标志性机器。
- 蓝色羊毛 → 染料来自青金石、羊毛来自线：热力膨胀**有机灌注机**灌注蛛网树苗产线；树苗可合成。
- **充能堆肥的富炉渣**：用**感应炉烧指南针**（一次仅耗 1 红石粉），加副产升级提高效率。
- 炭粉（炭磨粉）、硝石（粉碎火药）、沙砾（SAG 磨原石）等配套自行就近产。

## 4. 前期自动化起步

### 4.1 刷铁（前期批发钢吃铁）
- 海上会生成**科技枪的海上基地舰**，舰头生成**武装直升机**（生物）；击杀掉大量**铁块**、步枪子弹、控制组件。
- 用**套索/生物农场**抓捕刷取，弥补前期钢产线的铁缺口。
- ⚠️ 它会飞，**先做出喷气背包再去**，否则抓不到；中期可用「万物致理长存」+套索合出**无法破坏**词条长期刷。

### 4.2 矿物处理（矿石 → 锭，含倍产）

- **基础**：矿石直接进**熔炉**烧 → 1 锭（应急可以，**别长期这么烧**）。
- **倍产路线（按推荐顺序）**：

| 档位 | 做法 | 模组 | 供电 | 何时上 |
| --- | --- | --- | --- | --- |
| 1× | 熔炉直烧 | 原版 | 燃料 | 开局应急 |
| **2×** | 打粉 / 磨粉 | IC2 打粉机 / 热力膨胀磨粉机 | 电 / RF | 有电就做 |
| **2×** | 冶炼炉（1 矿 = 2 锭） | 匠魂 | 免电（岩浆） | 开局即可，离线批量 |
| **2×** | 多方块"磨粉机" + "熔炉" | 本包（模块化机械） | 电 | 任务推到就做 |
| **≈4×** | **SAG 磨粉机 + 磨珠** | **末影接口 (EIO)** | RF | **冲四倍的首选** |
| 3~5× | 净化仓 / 化学溶解（气态硫酸） | 通用机械 | RF + 气体 | 中期 |
| 8× | "矿物溶解机"（硫酸路线） | 本包魔改 | — | EP.08 之后 |

- **初期最高效的一条 = SAG 磨粉机 + 磨珠**：**末影磨珠**起步、**恒星合金磨珠**更好；选**副产高**的磨珠还能顺带刷副矿。本包玩家实测的"**四倍矿产**"（EP.03）走的就是这条。
- **八倍**："硫酸 + 矿石" / "矿物溶解机" → 直接 8 倍（后期，EP.08）。
- **挖矿端**：前期优先**数字化采矿**（见任务），手动挖太慢。
- ⚠️ 磨珠具体倍率/配方**以你档内 JEI 为准**（本包对磨粉做了魔改，倍率与副产可能与模组原版不同）。

| 金 | 金矿石 | 烧 / 磨粉 | |

| 铅 | 铅矿石 | 烧 / 磨粉 | 常作其它金属的副产 |
| 银 | 银矿石 | 烧 / 磨粉 | |

### 4.3 基岩粉（前期火焰机）
- ⚠️ **先关火焰蔓延**：`/gamerule doFireTick false`。
- **思路**：火焰 + 虚空箱子吸取掉落物。用**烈焰之炽焱**点燃（比打火石稳）。
- 小型机：找到**零素矿石**挖掉留坑，坑内倒烈焰之炽焱，粘性活塞 + 定时器加速火焰刷新，稳定产 8 火/150 tick；虚空箱子范围调 3。
- 大型机：火焰水被烈焰之炽焱点燃，发射器放火焰水桶，稳定 ~38 火/200 tick，可做 4–5 个主体并联。
- 攒够 **二重压缩基岩粉块（729 粉）**后，转 **SAG 磨粉机**（恒星合金电容 + 二重压缩块 + 磨珠）进入量产时代。

### 4.4 起 AE / ECO 系列
- ECO 系列（L 系列=驱动器/存东西的大箱子，F 系列=分子装配室，C 系列=CPU/合成存储器）就是本包的 AE。
- 基础流程：放控制器 → 按 R 用 JEI 调「动态结构」大小 → 投影到世界 → 控制器右键 → **木棍右键控制器**自动组装（充电的能源原件不会自动组装，要手动放）。
- F 系列把样板写好后**上传到智能样板总线**；C 系列做多少「晶振驱动」就要多少「闪存」，推荐用**线程核心**。
- 流体/气体样板：AE 网络里要放**流体离散器 / 气体离散器**，否则不识别系统内的流体/气体。

### 4.5 数据模型（前期就接触）
- 数据模型是**概率产出**，且**并行共用一个概率**：发 20 份材料并行没出 = 这 20 份全没出。
- 升级途径：小福利任务兑换（每种常见模型一次）→ 手刷对应怪 → 放进**生物演化推算模拟室**→ 后期换创造模式模型学习器。

### 4.6 匠魂（可选辅助线，别当主线）
- **结论**：**可行，但当"辅助工具线"，不要当主线。**
- **包里匠魂生态很全**：匠魂 + **匠魂盔甲**(ConArm) + **匠魂合金附加2**(TAIGA2) + **匠魂进化** + **匠魂工具升级** + **匠魂调整**(Tweakers)；不是被删减过的。
- **开局值得做的（~0.5–1 小时）**：
  - **冶炼炉**：早期**青铜**（3 铜 + 1 锡）、合金，以及"1 矿 → 288mb ≈ 2 锭"的早期翻倍；TAIGA2 还加了大量新合金。
  - **劈刀 + 活木（斩首 9）**：刷头刚需（见 §5.1）。
  - **干燥架**：腐肉干自动化（FAQ）。
  - **工具升级**：匠魂工具吃经验涨强化槽。
- **不建议当主线的理由**：
  - 开局就送**谐振通量电钻 + 全套 AE**，挖矿/存储/合成都不靠匠魂工具。
  - 中期**模块化机器**全面上位替代，匠魂工具等级投入基本打水漂。
  - 主线是 IC2 / AE / MEK / 模块化，**跟着任务书最省时间**。
  - 包里还带了「匠魂调整 (Tweakers Construct)」，具体数值是否被削弱以你版本实际为准。
- **时间账**：搭个最小 3×3 冶炼炉 + 焦黑炉 + 一把劈刀 + 干燥架 → 够用；匠魂盔甲/合金等主线有余力再补。
- 📄 **详细匠魂教材（含冶炼炉搭建示意图、部件/模具/强化/焦黑炉）**：见同目录 **`新星工程-匠魂攻略.md`**。

## 5. 前期战斗要点

### 5.1 刷头（斩首）
- 传统：**劈刀 + 活木** 达到斩首 9；但持劈刀时副手弓/法杖会被右键顶掉。
- 更优：主手**劈刀**、副手**科技枪的枪**（单手/双持不被顶掉，且吃斩首+掠夺）；推荐 **MAC10**（可打末影人）。
- 飞镖法：4 个活木飞镖（7 强化栏、75 耐久）右键全射，剩 5/75 时**强化仍生效**，副手配红石充能弓/匠魂法杖输出。

### 5.2 刷盖亚
- 到能刷盖亚时，**科技枪「战术霰弹枪」**贴脸打头：面板 8×4、结算合为一次伤害、**分别算爆头**，盖亚的限伤形同虚设。
- 盖亚 2 在 ~80 血召唤小怪：把血削到 ~100，掏战术霰弹枪贴脸爆头一发带走，跳过小怪群。燃烧弹 +10% 伤害更稳。

### 5.3 其它
- **遗灵/元素水晶**：跑图找巫术学遗灵极痛苦 → **随便抓一只塞进电动刷怪笼**，什么元素都会刷。
- **刷怪笼出精英怪**：在（EIO 电动）刷怪笼附近放一个**激活的信标**即可不刷精英怪。
- **血魔法反胃**：身上一直反胃且牛奶无效 = **气血网络没 LP 了**，拿起宝珠右键几下补 LP。

## 6. 前期常见坑（记住能省几十小时）

- **MEK 机械不能堆叠**：手上只拿一个再放置（1.17 已修复）。
- **不加配方的东西多半是被 ban 了**（如 MEK 物品管道，因为卡）。
- **流体不认原版桶**：模块化/装载流体请用热力大桶或各类液体储罐装在身上；流体样板也要用桶装流体才识别。
- **通量网络只能传 80w** → 打开控制器里的「禁用限制」。
- **区块加载失效 bug**（1.15 后可能出现，FTB/IC2/Flux 都不生效）→ 加 **Forged Carpet**，用 `/player ID spawn` 假人加载。
- **工匠作坊等不能自动化**：写样板用 ME 接口发材料到箱子手搓。
- **工程压印机串配方**：造两台，或把硅板配方换成硅晶圆配方。
- **复制机不工作**：多为超频升级问题（旧版超频放 17 个上限，配储能升级可到 19）。
- **手提包误进 AE 拿不出** → ME 输出总线 + 模糊卡标记手提包，输出到箱子。
- **反胃**见 §5.3；**镜像模块化机器替换能源输入**先给控制器红石信号再替换。
- **副本/奇点/中子素"先自动化再挂机"**：中期一定要先把奇点、中子素、基岩粉等大宗物品全自动，否则纯挂机要很久。
- **连锁挖矿（矿石挖掘 Ore Excavation）**：默认**按住 `~`（波浪号）**挖 = 连锁周围同种方块，松开 = 单块；`B` 编辑形状、`V` 切形状、`/undo_excavation` 撤销。**中文/非美式键盘的 `~` 常失效** → 到「按键设置」搜 `Excavation` 改绑**字母键**（如 `G`）。**谐振通量电钻**另按 **V 键**调范围到 **1×1**；它速度极快，**岩浆/悬崖边换普通镐**、全程潜行、**别垂直正下方挖**、备水桶。
- **怎么去下界**：黑曜石搭 **4×5** 门 + **打火石**点燃，**门一定要建在【主世界】**（官方 FAQ Q79：老版本把门建在**虚空世界**就进不去下界；1.17 起虚空世界已删除）。黑曜石用开局送的**谐振电钻**在"水+岩浆"处就能挖。
- **`/home` 相关设置（FTB 实用工具）**：三个节点——家的数量 `ftbutilities.homes.max`（默认 **1**）、冷却 `ftbutilities.homes.cooldown`（默认 **5m**）、前摇 `ftbutilities.homes.warmup`（默认 **5s**）。OP 指令：`/ranks set_permission player ftbutilities.homes.max 10`（同理 `.cooldown 0s`、`.warmup 0s`）；**时间必须带单位 `s`/`m`**，不写默认按 tick 算。或改 `local/ftbutilities/ranks.txt` 的 `[player]` 段加这三行（单人档在 `.minecraft/local/ftbutilities/ranks.txt`，需先启动一次生成）。**FTB 实用工具完整配置（主配置 + 全部权限节点）见同目录 `FTB实用工具-配置速查.md`。**
- **IC2 橡胶怎么来**：① 标准路线——主世界找**橡胶树**，合成**木龙头**对着树上的**橡胶口**右键得**粘性树脂**，**烧=1 橡胶 / 提取机=3 橡胶**（推荐后者），**橡胶木原木进提取机**也能出（可做树场自动化）；② **本包魔改更省事**：FAQ 明确写有**用史莱姆球（粘液球）合成橡胶**（无序合成）→ 刷史莱姆就能出橡胶。
- **橡胶树苗怎么种最好（树脂农场）**：**骨粉可催熟**，且树苗**上方仅 1 格空气也能正常催熟**，所以能密植。**推荐"间隔 1 格"**（树与树之间空 1 格）——这样树**四个面都露出来，树脂孔在任意一面都能刮到**；紧挨着种也行，但**贴着别的方块那一面的孔就够不到了**，且树叶会挡生长、要常手动打叶。刮树脂**只刮"湿"孔**（黄色，出 1~3 粘性树脂），**同一个孔可反复再生**：**"干"孔（棕色）会自己变回"湿"孔**再刮；**别乱点干孔**，乱点可能**永久废掉这个孔**（种植长出的树也一样有孔、一样可再生）；每块橡胶木**四个侧面只有一个孔**。`F3` 可看状态（无孔 `plan_y` / 湿 `wet_方向` / 干 `dry_方向`）。想**量产**别靠刮孔，走"**橡胶原木→提取机**"树场或"**史莱姆球合成**"。

## 8. 难度分布：这个包"难"在哪

> 主观判断，供选路线参考。

- **① 真正的难度核心 = 本包原创体系**：**模块化机械**（基于**模块化机械:社区版**，100+ 原创机器）+ **HyperNet 研究网络**。几乎每台机器都要自己搭"**控制器 + 材料输入/输出仓 + 能量仓 + 并行控制器**"的多方块结构，还要靠并行控制器等级提效率。**它不是外来模组，但门槛最高。**
- **② 外来模组里最烧脑（排位）**：
  1. **核电工艺 (NuclearCraft: Neoteric)** —— 裂变/聚变、热管理、燃料增殖，物理最复杂；后期托卡马克/裂变堆都压在上面。
  2. **高级火箭 (Advanced Rocketry)** —— 太空科技树长、坑最多。
  3. **龙之进化 (Draconic Evolution)** —— 不是"复杂"而是"肝"：海量材料 + 混沌守卫。
  4. **Psi** —— 要"写程序"（CAD），概念门槛高（可选）。
  5. **血魔法2 / 星辉魔法** —— 系统复杂（可选）。
- **不算难**：通用机械（Mekanism，文档全）、AE2（任务书带）、沉浸工程 —— 复杂但好学。
- **本包没有**：格雷科技、Reika 反应堆/旋转工艺 —— 别被"硬核"名头误导。
