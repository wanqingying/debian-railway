# 新星工程 · 匠魂攻略（Tinkers' Construct 2）

> **适用**：本包的 **匠魂2（MC 1.12.2）**。本包还带了 **匠魂盔甲 / 匠魂合金附加2 / 匠魂进化 / 匠魂工具升级 / 匠魂调整**，匠魂体系很完整，适合当主业玩。
>
> **先记住一条**：**做出冶炼炉之前，尽量不要用普通熔炉烧矿石**——冶炼炉 1 矿能出 **2 锭**，先用熔炉烧就是亏一半（教程原话："因此在做出冶炼炉前应尽量少烧制矿石，避免浪费"）。

---

## 0. 一条线速览

```
初期四件套（合成站/部件加工台/模具加工台/部件组装台）
    → 用燧石/骨头等做把镐子先挖矿
    → 攒水泥 → 烧焦黑砖 → 搭【冶炼炉】(双倍产矿 + 合金)
    → 升级【工具装配台】做重型工具（劈刀/锤子/伐木斧…）
    → 搭【焦黑炉】(超熔炉) + 【焦黑储罐】
    → 强化工具（斩首 / 时运 / 急速…）
```

## 1. 初期四件套 + 模具

四台设备（缺材料就先做前两台）：

| 设备 | 作用 |
| --- | --- |
| **合成站** | 相当于工作台；退出后保存里面物品（当箱子）；**把相邻的匠魂设备连成一个 GUI** |
| **部件加工台** | 把材料 + 模具 → 做成**部件**（镐头、手柄…） |
| **模具加工台** | 给木板**打孔**做成各种模具 |
| **部件组装台** | 把部件**组装成工具** |

- **成本**：工作台×2 + 模具×3 + 原木×1 + 木板×1 = 木板×17 = 原木×5。
- **联动**：打开任意一台的 GUI，可直接切到相邻设备的 GUI（**同一种设备只能有 1 台**，否则会断开）。这一步靠"合成站"实现。
- **基础模具 7 个**：镐头、铲头、斧头、剑刃、宽护手、绑定结、手柄。材料紧张时**同一个模具可反复打孔**，不必做一堆。

**早期零件材料**（没有铁也能做工具）：

| 材料 | 挖掘等级 | 特点 | 处理方式 |
| --- | --- | --- | --- |
| 燧石 | 铁 | 挖掘速度 5，快 | 部件加工台 |
| 骨头 | 铁 | 手柄倍率 1.1（耐久高） | 部件加工台 |
| 仙人掌 | 铁 | 攻速快 | 部件加工台 |
| 黑曜石 | 钴 | 挖掘等级高（能挖钴） | 部件加工台 / 浇筑 |
| 木 | 石头 | **手柄倍率 = 1**，适合做手柄 | 部件加工台 |

> 提示：3 个砂砾可无序合成 1 燧石。

## 2. 🔥 冶炼炉（重点：双倍产矿 + 合金）

### 2.1 材料准备

```
黏土 + 沙子 + 砂砾  ──合成──▶  水泥  ──熔炉烧──▶  焦黑砖
焦黑砖 ──合成──▶ 焦黑砖块（可再合成焦黑玻璃 / 焦黑储存装置等）
```
- 焦黑砖块还能合成各种样式（焦黑石、焦黑路面、焦黑玻璃…）。
- **焦黑玻璃**：在墙上用，能看见内部液体（**不要在墙上留洞**）。
- **焦黑储存装置**：可替代墙块，增加燃料容量。
- 沙子可用红沙替代；黏土山是刷黏土的好地方。

### 2.2 六大部件

| 部件 | 作用 | 备注 |
| --- | --- | --- |
| **冶炼炉控制器** | 核心 + 投料口（GUI） | 冒**火花** = 搭建成功 |
| **焦黑储罐** | 装**岩浆**当燃料 | 容量 4B；敲掉保留液体；空余 ≥1B 可用桶倒液 |
| **排液口** | 液体进/出 | 用桶右键可**倒进去**；配合**龙头**导出 |
| **焦黑砖块** | 搭建材料 | 见 2.1 |
| **龙头** | 配合排液口导出液体 | 右键 或 红石信号激活 |
| **浇筑台** | 浇筑铸模 / 金属部件 | 右键放取物品；配**铸造盆**浇金属块 |
| 焦黑玻璃 / 浇筑道 / 铸造盆 | 可选 | 浇筑道=焦黑砖按"船"形合成→3 个，只能**导入**排液口，可存 4mB |

### 2.3 搭建步骤 + 示意图

**规则**：地基是 **N×N 焦黑砖**（最小 3×3，5×5 / 7×7 都行，**最大 11×11**）；四周砌**墙**，**至少 2 层高**；墙只能由**焦黑类方块 / 焦黑玻璃 / 焦黑储存装置**构成，**不能有洞**；内部全空（炉膛）。

**① 打地基**：3×3 全部铺焦黑砖。
**② 砌第一层墙**：在周长这一圈放入 **控制器 / 焦黑储罐 / 排液口**，其余用焦黑砖。
**③ 判断成功**：控制器冒火花 → 右键打开 GUI。**④ 装出液口**：在排液口外侧贴**龙头**，龙头正下方放**浇筑台 / 铸造盆**。

**俯视示意图（3×3 最小）**

```
        北
   ┌────┬────┬────┐
   │焦砖│储罐│焦砖│      ← 这一圈 = 墙（≥2 层，不能有洞）
   ├────┼────┼────┤
   │控制│炉膛│排液│      ← 中间"炉膛"是空的：矿石/金属丢这里融化
   ├────┼────┼────┤
   │焦砖│焦砖│焦砖│
   └────┴────┴────┘
        南（让"排液"这面朝向你，方便接龙头）
        ▲
        │ 每一格下面（地基）= 焦黑砖
```

> 图例：`焦砖`=焦黑砖块 ｜ `储罐`=焦黑储罐（岩浆）｜ `控制`=冶炼炉控制器 ｜ `排液`=排液口 ｜ `炉膛`=内部空。
> 想加大容量就**往上加墙的层数**（每加一层，内部空间更大）。

### 2.4 出液示意（排液口 → 龙头 → 浇筑台）

```
   [排液口]（嵌在墙上）
       │ 贴外侧
       ▼
   [龙头]  ← 右键 或 给红石信号 = 出一次液
       │
       ▼
   [浇筑台]  →  一次凝固 1 个锭 / 1 个铸模      （144 mB）
   [铸造盆]  →  一次凝固 1 个金属块（= 9 锭）   （1296 mB）
```

### 2.4b 浇注道（一个龙头 → 多个目标）★

**可以**——用**浇注道 (Casting Channel)** 就能让**一个排液口/龙头**给**多个浇筑台/铸造盆**供液。

```
   [排液口] → [龙头]
                 │
   [浇注道]——————┼——————[浇注道]————————[浇注道]
      │                  │                │
   [浇筑台]           [浇筑台]          [铸造盆]
```

- **放法**：龙头**正下方**放浇注道，浇注道延伸出去；把**浇筑台/铸造盆**放在浇注道的**相邻格**（下方/侧面）即可被填充。
- **右键浇注道的一端**可切换状态——"**对外流动**"，控制液体从哪一端流向目标。
- 它本质是"**管道**"，能给**多个输出**供液（官方 wiki：properly setup 可 multiple outputs）；也能接到其它支持流体输入输出的机器。
- **坑**：
  - **不是"精准定量"**——直接龙头浇注会只放所需量，经浇注道可能**多填/残留**；换金属时道里会**残留液体**，要清理。
  - 多目标时是**按连接顺序填充**，不是同时精确分配；做自动化要自己控制（例如前一格冷却完再放行）。

### 2.5 铸模（Casts）

- **金** 可做铸模：每个消耗 **2 锭**；**铝黄铜**只消耗 **1 锭**（更省）。
- 早期没有铁镐挖不了金？**用黏土**：把黏土丢进冶炼炉融成黏土浆，浇到浇筑台上的部件上 → 做出**一次性铸模**（只能用一次就碎）。
- 铸模可在模具加工台打孔变成木制模具；铸模能直接在部件加工台上做部件。

### 2.6 冶炼炉能干什么

1. **双倍产矿**：丢 **2 个矿石**进去 → 融出 **4 锭**（1 矿 = 288mB = 2 锭）。**这就是"少烧东西"的核心**。
2. **合金**：多种金属一起融会**自动按比例合金**，例如 **青铜 = 3 铜 + 1 锡**（→ 4 锭青铜）、骑士史莱姆等；本包还有 **匠魂合金附加2** 加的一堆新合金。
3. **融化整块/装备**：可把成品装备、金属块融回液体。

> 不想合金时：用 **焦黑储罐**单独存液体（单格容量远大于冶炼炉，且**不会合金**）。

### 2.7 搭建成本（教程给出的 3×3 方案）

```
焦黑砖块×18 + 控制器×1 + 焦黑储罐×1 + 排液口×1 + 龙头×1 + 浇筑台×1
= 焦黑砖×104 + 玻璃×1
= 水泥×104 + 沙子×1
= 黏土×52 + 砂砾×52 + 沙子×53
```

## 3. 🔥 焦黑炉（超·熔炉）

匠魂的"升级熔炉"：**每个槽位同时烧 16 个**，烧完**原地变成产物**（没有专门取物口）。

**搭建规则**
- **地基**：实心焦黑方块（边缘可省）。
- **第二层**：放 **焦黑熔炉控制器**；从第二层到**倒数第二层**，**四角**可放**焦黑储存装置**（增加燃料上限）。
- **中间层**（第三层~倒数第二层）：可省略，也可用焦黑方块围一圈。
- **顶层**：用焦黑方块 / 下半砖 / 正放楼梯**封顶**（边缘可省）。
- **成功条件**：底层必须是完整方块；顶层必须密封；内部必须全是空气（漏风/偷工减料都不行）。
- **槽位**：基础 **9 槽**，**内部每多 1 格空气 +3 槽位**。

```
       顶层（封口）
   ┌────┬────┬────┐
   │焦砖│焦砖│焦砖│
   ├────┼────┼────┤
   │焦砖│ 空 │焦砖│   ← 中间每 1 格空气 +3 槽位
   ├────┼────┼────┤
   │储罐│控制│储罐│   ← 四角可换焦黑储罐（加燃料上限）
   ├────┼────┼────┤
   │焦砖│焦砖│焦砖│
   └────┴────┴────┘
       地基（实心焦黑方块）
```

> 注意：可二次熔炼的物品烧完**不会自动进第二次**，要手动取出再放；已显示"熔炼完成"的物品再放会变成"无法熔炼"。

## 4. 工具强化速查

- **强化槽**默认 **3 个**；每加一个**纸部件** +1 槽；加了**匠魂工具升级**后按工具等级再给额外槽。
- 常用强化（除"强化/灵魂绑定/刻印"外，每级占 1 槽；时运/爆破这类始终占 1 槽）：

| 强化 | 作用 |
| --- | --- |
| **急速** | 提高挖掘/攻击/拉弓速度 |
| **时运** | 提高产物成倍掉落概率与倍率 |
| **精准采集** | 掉落原方块（降速降伤） |
| **耐久** | 每级 +20% 不掉耐久、+10% 双倍消耗；5 级基本不损 |
| **斩首** | 每级 +10% 掉头颅（刷凋零头/怪头） |
| **亡灵杀手 / 节肢杀手** | 对亡灵/节肢加伤 |
| **炽热** | 攻击使生物着火 |
| **生命窃取** | 每级 +1 吸血 |
| **竖直扩展 / 水平扩展** | 挖掘时多挖一行（重型工具超耗耐久） |
| **修复苔藓** | 吸经验球修工具 |
| **爆破** | 更快，但概率不掉落（消圆石用） |
| **灵魂绑定** | 死亡不掉落 |
| **刻印** | 让工具获得某材料的附加属性（不改面板） |

## 5. 在本包（新星工程）里怎么用匠魂

- **冶炼炉 = 早期青铜来源**：3 铜 + 1 锡 → 青铜（前期机器/感应炉要）。
- **劈刀 + 活木（斩首 9）**：刷头刚需（见主攻略 §5.1）。
- **干燥架**：腐肉干自动化（主攻略"常见问题答疑"里官方给的方案）。
- **骑士史莱姆**：紫色史莱姆空岛产物，前中期大量收集。
- **别当主线**：本包开局就送**谐振通量电钻 + 全套 AE**，中后期**模块化机器**全面上位替代；匠魂当"青铜 + 刷头 + 干燥架 + 顺手工具"很划算，硬肝工具等级性价比低（详见主攻略 §4.6）。

## 6. 匠魂调整（Tweakers Construct）能改什么

- **纯配置的匠魂2 魔改模组**（作者 RCXcrafter，1.12.2），**不添加任何物品/方块**；它只通过**配置文件**（本包里通常还配合 CraftTweaker / ContentTweaker 脚本）去改匠魂的数值——所以"改了什么"取决于整合包作者怎么写，**不是模组固定改了什么**。
- **可改项**（官方列出的全部）：
  1. 修改**特定工具部件**的耗材份数；
  2. 按**百分比**改**耐久 / 采掘速度 / 护甲值**；
  3. 修改**任意材料**的特定参数（兼容**匠魂盔甲 ConArm**、**工匠防御**）；
  4. 修改材料的**特殊属性（trait）**；
  5. **禁用任意材料**；
  6. **禁用任意强化**；
  7. 禁用工具的**防岩浆烧毁 / 防自然清除**特性；
  8. （1.5.4+）**按 MODID 批量禁用**某附属的材料。
- **本包具体改了哪些**：需看你**自己安装**里 —— `config/` 下名字含 **tweakers** 的配置、`scripts/` 里的 CrT/CoT 脚本（本包很多匠魂改动其实在脚本里）。
- **生效值以游戏内 JEI / 《匠魂宝典》显示为准**（那才是真正跑的值）。
- 相关：`config/tconevo.cfg`（**匠魂进化**）里的 `disableDamageCutoff=true` 可**禁用伤害衰减**，武器会更强。
