# N5 gaps (game-development weaknesses)

- **No peer-reviewed measurement of style drift across an asset set was found.** Searching arXiv ("game asset" + consistency = 0 hits; "style consistency" + game = 7, all asset-*generation* methods papers) and the web produced only vendor/marketing claims with invented-looking numbers (e.g. a sprite tool blog asserting "70-85% color consistency across batches"), which were rejected as unverifiable T3. The consistency claim therefore rests on AIIDE 2025's qualitative statement plus the C4/C9 synthesis themes, not on a measured drift figure.
- **Audio mix / mix bus work is uncovered.** No 2024-2026 study measuring whether automated mixing or loudness metrics predict perceived game mix quality was located; sub-area 2 is represented by game feel, particles/SFX feedback, and camera instead.
- **The most direct "automated game design cannot do juice" experiment is out of window.** Johansen & Cook, "Challenges in Generating Juice Effects for Automatically Designed Games" (AIIDE 2021, locally read) ran a 112-participant study where expert-designed juice beat generated sets; it is 2021, so it was not recorded as a load-bearing claim.
- **Engine-API hallucination is only indirectly measured.** Saei et al. 2025 (the primary source behind the "frequent hallucinations" attribution) could not be located as an open full text; the claim is carried by SE4Games' citation plus its own accuracy/completeness split (90% / 10% on Unreal), which measures usefulness, not hallucination rate per se.
- **SIGGRAPH/ACM pages blocked or bot-gated:** ojs.aaai.org (Anubis), dl.acm.org and mdpi.com returned 403/BotStopper, so the ACM version of the qualitative synthesis and the MDPI scoping review were read only through arXiv mirrors.
- **No studio-scale deployment evidence.** Nothing found that measures agent-authored game code inside a shipping production codebase; all code evidence is benchmark or single-project case study.
