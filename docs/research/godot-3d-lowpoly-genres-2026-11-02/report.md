# 3D 低模 + 统一着色器：该做哪些品类

**前提：** 单人、Godot、强程序、弱美术、中小体量（6–12 个月）、Steam 定价 ¥10–30、3D 低多边形 + 统一卡通着色器。
**日期：** 2026-11-02
**数据：** 外部品类基准（Immutable 107 个 tag、Steamograph、Game Oracle 饱和度）+ 自采 2026 年 Indie 样本 646 款（按 tag 统计“零评测率”）。

## 结论

**优先级排序（针对“3D 低模 + 弱美术 + 强程序”这一组合）：**

| 档 | 品类 | 为什么适合你 | 主要风险 |
|---|---|---|---|
| **T1** | **殖民地 / 基地建造**（Colony Sim、Base Building） | 零角色动画、系统深度换内容量、固定相机可藏 3D 短板；tag 中位收入 $17.3k，样本零评测率 58% | 与 RimWorld 正面比较；内容量要求高 |
| **T1** | **自动化 / 工厂**（Automation） | 程序员的天然主场：状态机、物流、数值；美术只需 10–20 种模块；平均销量 9.8 万、饱和度 5.8（偏低） | 玩家会拿 Satisfactory 对标；单人做 3D 体量大 |
| **T1** | **管理 / 店铺模拟**（Management、Shop Keeper） | 场景小、道具重复、无动画；样本零评测率 56%（全样本最好一档）；Simulation 中位 $7.4k | 极度拥挤；内容更新是无底洞 |
| **T2** | **城市建造 / 塔防** | 单位简单、动画极少；城市建造饱和度 5.7、塔防平均销量 7.4 万 | 塔防同质化严重；城市建造 UI 工作量大 |
| **T2** | **农场 / 生活模拟（3D 低模）** | 道具+环境为主、无复杂动画；Farm Sim 中位 $8.7k | 赛道拥挤，需要明确钩子 |
| **T2** | **生存建造（小地图）** | 系统驱动、程序化地图；Open World Survival Craft 中位 $10.2 万（但那是团队体量） | 体量容易失控，必须砍到“一张图” |
| **T3** | **低模恐怖（PSX 风）** | 单位美术成本最低：黑暗+低分辨率掩盖一切；程序强项（AI、事件、程序化） | 赛道已拥挤（Lethal Company 之后）；音频与氛围是隐形工作量 |
| **T3** | **物理 / 派对沙盒** | 程序强项（物理、网络）；传播性强 | 需要联机与“好玩”的物理手感，失败率高 |
| **T3** | **解谜 / 密室逃脱** | 无动画、美术靠环境；完成度高 | 天花板低，中位收入 $2.4k |
| **不做** | 动作 / ARPG / 平台跳跃 / FPS 竞技 / 开放世界 / 叙事 RPG | 全部吃“动画 + 手感 + 面部表演”，正是你的短板 | — |

## 三、为什么这些品类适合 3D 低模

| 特征 | 收益 |
|---|---|
| 没有角色骨骼动画 | AI 3D 最弱的一环（脸、手、权重）直接被绕开 |
| 大量重复道具 | AI 生成 20–30 个模块，其余靠实例化/换材质/缩放 |
| 固定或半固定相机 | 不需要为每个角度打磨模型；等距视角还能用“微缩模型”美学兜底 |
| 纯色/低模是风格而非缺陷 | 低模 + 卡通着色器的“廉价感”可以被解释为 art direction |
| 系统复杂度 = 深度 | 你的编程优势直接转化为玩法深度，而不是资产数量 |
| 数值/程序化 | 用生成器替代手工关卡，内容量不靠美术堆 |

反过来，动作类的问题不是“做不出来”，而是：手感需要逐帧调、角色需要动画、镜头需要打磨——三项都吃审美判断。

## 四、具体细分方向（可直接立项的 5 个）

1. **带 Z 轴的殖民地模拟**：RimWorld 是 2D 平面，3D 低模可以做“多层基地 + 垂直物流”。差异化来自空间，而不是内容量。
2. **自动化 + 塔防**：Mindustry 的 3D 低模版；用“防线被生产线喂养”做循环。
3. **单一场景的管理模拟**：加油站/维修店/网吧，一个场景 + 20 个道具 + 一条升级曲线；靠“下一件设备”驱动留存。
4. **程序化地图的低模恐怖**：单人版 Lethal Company 的“下矿—搬货—撤离”循环；黑暗掩盖美术，程序化解决内容量。
5. **物理建造解谜**：桥/塔/轨道建造 + 物理验证；关卡由玩家自造，内容量外包给物理引擎。

## 五、不推荐的理由（逐条）

- **动作 / ARPG / 平台跳跃**：动画与手感是核心资产，AI 补不了；玩家对动作的容错最低。样本零评测率 85%。
- **FPS 竞技**：地图、枪械手感、网络同步三座山；低模可以省美术，但省不了动画与平衡。
- **开放世界 / 生存建造（大世界）**：中位收入最高（$10.2 万），但那是团队体量；单人做必砍成“一张图”，否则做不完。
- **叙事 RPG**：需要面部、演出、大量角色；AI 3D 的脸是硬伤。
- **纯解谜**：适合练手，但中位收入 $2.4k，且很难靠“系统深度”建立壁垒。

## 六、选择流程

1. 你能接受“没有角色表演”吗？不能 → 回去做 2D 叙事，3D 低模不适合。
2. 玩法核心是“系统/数值/空间”还是“动作/手感”？前者 → 本清单；后者 → 换方向。
3. 单局时长 2–8 小时、可重复？T1 品类天然满足；动作类需要更多内容。
4. 有没有一个“3D 才成立”的机制？垂直空间、物理、第一人称视角、光照——没有的话，2D 更便宜。
