# 让 AI 像玩家一样玩：派系领袖 / 首领 / 队友的决策模型

**问题：** 不做“每个 NPC 的小动作”，而是让关键角色（派系领袖、敌人首领、队友）像玩家一样做宏观决策——可行吗？该用什么模型？
**日期：** 2026-11-02

## 结论

**可行，而且这恰好是 LLM 唯一被证明能做到人类水平的用法——但前提是“模型不做全部决策”，而是“规划器做决策，模型做意图与沟通”。**

三条硬证据：

| 案例 | 做法 | 结果 |
|---|---|---|
| **Cicero**（Diplomacy） | **规划引擎（piKL）+ 2.7B 对话模型**，模型只按规划出的“意图”说话 | 与人类对战 40 局，得分是人类平均的 **2 倍**，进入前 10% [S1][S2] |
| **Vox Deorum**（Civ V） | **LLM 做宏观战略，战术交给原有 AI** 执行；2,327 局完整对局 | 开源 LLM（GPT-OSS-120B、GLM-4.6）与手工调优的 Vox Populi AI **统计上打平**，且打法风格明显不同 [S3] |
| **CivBench**（Civ VI） | 纯 LLM 通过 76 个 MCP 工具直接玩 | 前沿模型 23 局只赢 3 局；常忘记查关键状态，计划执行率只有 48–66% [S4] |

**读懂这三条的差别，就是全部答案：**

- 纯 LLM 玩策略游戏，**打不过游戏自带的 AI**（CivBench）；
- LLM 做“宏观意图”、底层交给算法执行，**能与调优过的 AI 打平**（Vox Deorum）；
- 规划器做决策、模型只负责表达与谈判，**能超过人类平均两倍**（Cicero）。

所以你要的“操作和决策跟玩家持平的智能”，核心不是更强的模型，而是**一个能在你的游戏里做规划的智能体框架**。

## 一、为什么 Cicero 是模板

Cicero 的结构（论文原文）：

1. **战略推理模块**：根据盘面与对话，预测每个玩家会怎么走；
2. **规划算法（piKL）**：在预测之上迭代，选出自己的最优动作，同时保持“像人”；
3. **意图（intent）**：把规划结果翻译成“我要和英国一起打进勃艮第”这样的结构化意图；
4. **对话模型**：**以意图为条件**生成台词；
5. **过滤器**：剔除不合语法/不合意图/不合策略的候选。

关键一句原文：**“以意图为条件，让对话模型不必承担‘哪些动作合法、哪些战略有利’的责任。”**

这就是你要的架构：**模型不负责正确性，只负责表达与风格。** 正确性由规划器保证。

## 二、放到你的游戏里：四层

| 层 | 职责 | 实现 | 频率 |
|---|---|---|---|
| **1. Agent 接口** | 把游戏变成“可被智能体玩”的环境 | `observe()` 返回过滤后的 JSON 状态；`actions()` 返回**合法动作表**；`step(a)` 落子 | 每回合 |
| **2. 规划器** | 真正的决策 | HTN / GOAP / 效用搜索；可用 bot 自对弈调参 | 每回合，< 10 ms |
| **3. 意图层** | 性格、目标、外交姿态 | 本地 1–3B + JSON schema，输出 `{intent, priority, diplomacy}` | 每 30–60 秒 / 每 N 回合 |
| **4. 表达层** | 让玩家看见“它在想什么” | 使者、谣言、斥候报告、谈判台词（可由意图条件化生成） | 事件触发 |

**第 1 层是整个项目的分水岭。** 如果游戏从第一天就能被一个文本接口完整驱动，那么：AI 对手、bot 自对弈平衡测试、回放、自动化 QA、甚至“把玩家操作录成训练数据”全部顺带得到。如果做不到，后面三层都无从谈起。

## 三、成本：这个用法恰好落在可承受区间

关键角色只有 3–5 个，且是**人类节奏**（每 30–60 秒或每回合一次），不是每 tick：

| 配置 | 决策频率 | 10 小时/玩家（远程 flash-lite 价） |
|---|---|---:|
| 4 个领袖，每 30 秒 | 480 次/小时 | $0.98 |
| 4 个领袖，每 60 秒 | 240 次/小时 | $0.49 |
| 4 个领袖，每回合（≈2 分钟） | 120 次/小时 | $0.24 |
| 本地 1–3B | 同上 | **$0**（4 个领袖 × 2 次/分 = 8 次/分，CPU 占用 15–25%） |

对照 ¥30 的净收入（约 $2.0）：远程方案占 12–49%，仍然不该由你承担；**本地模型是唯一干净的解法**，而且这个频率下延迟完全可接受（异步、错峰、结果写进存档）。

## 四、本地 1–3B 能胜任“宏观意图”吗

能，但要限定任务形态：

- **能做**：在 10 个高层意图里选一个（扩张/囤粮/结盟/备战/复仇），并给出目标对象与优先级——这是**分类 + 结构化输出**，小模型表现可以接受；
- **不能做**：300 回合的长程规划、资源账目推演、多步欺骗——CivBench 里连前沿模型都做不好（计划执行率 48–66%）。

所以分工必须是：**规划器管长程与正确性，模型管“现在更想干什么”和“怎么把它说出来”。** 这也正好是 Cicero 的分工。

## 五、还要解决三个产品问题

1. **公平感**：AI 必须和玩家受同样的规则与信息约束（同样的动作表、同样的战争迷雾）。否则玩家会觉得“它在作弊”，赢了也不爽。
2. **可读性**：AI 的意图要在游戏里留下痕迹（使者来访、边境集结、贸易封锁）。**看不懂的强 AI 比看得懂的弱 AI 更让人厌烦。**
3. **难度**：不要用“变笨”做难度。用资源系数、信息延迟、反应时间做难度——保留它的“聪明”，只调它的“手速与家底”。

## 六、可行性判断

| 目标 | 可行性 | 说明 |
|---|---|---|
| AI 派系领袖会扩张、结盟、背刺、备战 | **高** | 规划器 + 状态机即可，不需要 LLM |
| 领袖有性格、谈判有语气、决策可解释 | **高** | 本地 1–3B + 意图条件化（Cicero 路线） |
| AI 打得过大多数玩家 | **中** | 需要 bot 自对弈调参；这是工程活，不是模型活 |
| AI 像人一样“失误但合理” | **中** | 需要刻意注入噪声与偏好，不能追求最优 |
| 纯 LLM 端到端玩你的游戏 | **低** | CivBench 证明连前沿模型都打不过内置 AI |
| 单人 9 个月做完以上全部 | **低–中** | 建议 v1 只做“规划器 + 意图层”，表达层可后置 |

## 七、建议的落地顺序

1. **先做 Agent 接口 + 无头模式**（2–3 周）。这是所有后续能力的地基，也能立刻换来 bot 自对弈测试。
2. **写一个能赢“简单脚本 AI”的规划器**（1–2 个月）。目标不是打赢人，是“行为看起来有长期计划”。
3. **接本地 1–3B 的意图层**（2–4 周）。只给 3–5 个领袖，JSON 约束，异步，可关闭。
4. **做表达层**（1 个月）。使者、谣言、谈判——这是玩家真正感知到“智能”的地方。
5. **用 bot 自对弈做平衡**（持续）。同一套接口，让两个 AI 互相打，跑几千局找失衡。
