# AI 编程模型定价公式

真实成本估算：把"缓存读/写 + 输入/输出"的 token 分布换算成每 1M 输入 token 的价格。

## 符号

| 符号 | 含义 |
| --- | --- |
| `Pin` | 输入单价（$/1M token） |
| `Pout` | 输出单价（$/1M token），通常 ≈ 4~5 × Pin |
| `Cr` | 缓存读单价 = 0.1 × Pin（Anthropic / OpenAI 实测） |
| `Cw` | 缓存写单价 = 1.25 × Pin（5min TTL，Anthropic / OpenAI 实测） |
| `h` | 输入侧缓存命中率 = 缓存读 ÷ (读+写+新鲜输入)，默认 **0.96** |
| `k` | 输出 token ÷ 输入 token，agent 多轮场景 ≈ 0.05~0.15，默认 0.1 |

## 公式

每 1M 输入 token 的真实成本（含输出）：

```
P(1M in) = Pin · [ 1.25·(1−h) + 0.1·h ]  +  k · Pout
```

代入 **h = 96%**：

```
P(1M in) = 0.146·Pin + k·Pout      ($/1M 输入 token)
```

每"混合 token"均价（输出摊进输入，便于不同 k 对比）：

```
P̄ = (0.146·Pin + k·Pout) / (1 + k)
```

### 系数推导

- 命中部分：占 `h`，按输入价 10% 计 → `0.1·h`
- 新写部分：占 `1−h`，按输入价 125% 计 → `1.25·(1−h)`
- 净输入系数 = `1.25·(1−h) + 0.1·h`，h=0.96 时 = **0.146**

## 敏感度

| h | 输入系数 `1.25(1−h)+0.1h` |
| --- | --- |
| 90% | 0.215 |
| **96%** | **0.146** |
| 98% | 0.123 |

> h 每 +6 个百分点 ≈ 输入成本再降 1/3。缓存工程（保持前缀稳定、控制每轮新增量）比选模型更能决定账单。k 越大（thinking/长输出）真实成本越高。

## 数值验证（k=0.1）

| 模型 | Pin | Pout | 无缓存成本 | h=96% 成本 | 节省 |
| --- | --- | --- | --- | --- | --- |
| gpt-5.6-luna | $0.20 | $1.20 | $0.32 | **$0.149** | 53% |
| Claude Sonnet 4.6 | $3 | $15 | $4.5 | **$1.94** | 57% |
| gpt-5.6-sol | $4 | $20 | $6 | **$2.58** | 57% |
| DeepSeek V4 Flash | $0.28 | $0.43 | $0.31 | **$0.084** | 73% |

无缓存成本 = `1M × (Pin + k·Pout)`；h=96% 把输入侧压到 14.6%。

## 参考来源

- Anthropic prompt caching 定价：缓存读 = 输入价 10%，缓存写（5min TTL）= 1.25× 输入价，1h TTL = 2×
- OpenAI 定价页：cached input ≈ 输入价 10%，cache write ≈ 1.25×
- 缓存命中率口径：输入侧 `cache_read / (read+write+fresh)`（Anthropic usage 字段）
