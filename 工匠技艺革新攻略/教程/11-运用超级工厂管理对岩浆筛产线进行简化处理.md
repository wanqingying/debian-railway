# 运用超级工厂管理对岩浆筛产线进行简化处理

> 作者：1 · 来源：https://www.mcmod.cn/post/4901.html
> 图片 2 张

关于如何使用sfm简化岩浆筛产线

every 5 ticks do

INPUT forge_energy:: FROM "能量立方" north side

Input forge_energy:: from A top side

output forge_energy:: to A bottom side

end

这里是将能量从能量立方中输出进入岩浆筛所需的离心机的代码，建议立方尽可能制做终极以上的等级，因为sfm是20t一次运行，也就是一秒（能量的输入机器的方向可以任意更改，但是能量从立方中输出一定要注意立方的哪些面是输出的）

every 20 ticks do

input * from lz

output to d

end

这里是将离心富集炉渣的离心机（记得开自动弹出）旁边接入的产物桶中的部分可进入磨粉机中的炉渣导出并输出到磨粉机中，当然如果不喜欢贴着桶自动弹出也可以用sfm将离心机中的炉渣导出到标记好的存储点中（也可以直接导出给离心机和磨粉机，我个人比较喜欢接一下缓存），只需要多标记一下多写一段就行）

every 20 ticks do

input * from lz

output to e

end

这里也是输出富集炉渣离心后的产物，同上，但是这段是给离心机再处理的，上面那段是给磨粉机的（建议不要偷懒省产线少做离心机和磨粉机，这样效率很慢）

every 20 ticks do

input * from e

input * from chanwu

input * from d

input * from f

output * to cunchu

end

这边是将不再需要烧炼的产物直接接入存储。

every 20 ticks do

input kubejs:powdered_slag from g

output kubejs:powdered_slag to f

end

这边直接用物品标签将矿物炉渣粉输出到离心机再加工成粗矿

every 20 ticks do

input from "未烧炼粉"

output to "烧炼"

input *copper from d

output *copper to "烧炼"

input *raw_iron from d

output *raw_iron to "烧炼"

input *raw_lead from d

output *raw_lead to "烧炼"

input *raw_tin from d

output *raw_tin to "烧炼"

end

这边是烧炼，直接将各种粗矿从中转存储中取出并运输到烧炼的机动鼓风机。
