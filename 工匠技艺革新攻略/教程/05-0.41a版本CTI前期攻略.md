# 0.41a版本CTI前期攻略

在0.41a中更新了一个非常实用的结构：狐狸小屋（fox house），它内部存有的大量资源能在初期给我们提供快速开局的能力。【攻略中一些材料的获取或者特性将在文末说明】

进入存档后，我们可以在任务书的序章章节里领取开局装备。领取装备后，我们先就地使用连锁挖取一组原石。随后在地图上找到狐狸小屋（很显眼的橙色）快速进入狐狸小屋，狐狸小屋中心的空间是一片草地，在种着甜浆果的方块下方埋有一个奖励箱，里面会固定刷新16金币，

一个附魔金苹果，12个粗钴与6个粗阿迪特。

0.41a在任务书旁边添加了SDM商店，我们将手中的金币卖掉（请留下三枚金币），就可以在商店中买一个下界合金背包，拿到背包将狐狸小屋里的箱子全部扫荡一遍。箱子中包含大量木头，铁，小麦，线，皮革和粘液球，以及非常多种类的食物。除了箱子外，狐狸小屋中的一些功能性方块也可以一并带走，比如砧板和炼药台。

还记得我让你留下的三枚金币吗，打开任务书，找到来自亚马龙的游商这一节，在章节的左上角会有提交金币购买探险家指南针的可重复任务。

接下来使用指南针搜索sear house，定位后前往，将匠魂小屋的流体源都堵上，开挖（你赶到小屋时应该到晚上了，先睡一觉）将可以组成匠魂炉的方块全部带走包括村民旁边的焦黑融化炉（用于完成任务）由于新手镐子在挖掘完方块前会消耗完耐久度，建议挖掘时自己做一把铁镐/钻石镐。

使用指南针搜索fox house（可以跳过）但是我更建议再找一个狐狸小屋获取金币，以方便购买材料，在跑图的途中遇到锇矿石可以挖一点（用于制作强化萤石）

在主世界搭个平台做基地并插下传送石碑（也可以使用任务书中游玩前需知中送你的全息永夜世界投影板进入永夜世界）现在开始推进开始与匠魂章节。在商店买一个钻石箱子把背包中的杂物存一下，搭建匠魂炉子（为了完成任务你需要额外做三个排液口）并在商店中购买（28+16+6+2）共52个铜，（16+14+32）共62个沙子，16个沙砾，用于制作32个水泥，28个工匠青铜，一个粗糙抢夺宝珠，8个窑砖。

推进任务线直到获取工匠砧领取黑曜石。

（如果不担心生存问题可以在攻略boss前再制作）将12个黑曜石与16铜融入匠魂炉完成合金后（在等待熔炼的时间吃食物撑血量），再加入4金做四件盔甲铸模（也可在焦褐小屋中获取）然后制作黑曜石-黑曜石青铜四件套（作者更建议制作层板盔甲）。另外，如果你挖掘了锇矿，可以制作一个强化萤石的护甲部件以获取夜视，两个部件则可以让猪灵无视你。

在主世界搭建地狱传送门，进入地狱后插传送石碑，用指南针搜索焦褐小屋（Scorch house）再搜一下下届要塞，确定两个地点后使用任务给的飞行药水前往，优先扫荡焦褐小屋获取烈焰血，下届合金等材料以及焦褐方块。前往下届要塞获取烈焰人刷怪笼（任务有送纸箱）以及地狱疣。此时初始章节完成，奖励一个工程师锤与机动扳手，使用工程师锤右键窑砖多方块，用钴和下界残骸碎片制作马玉灵，马玉灵用于锻造台将钻石手杖（合成两个）升级为无尽手杖，任务书领取天使与破坏核心，分别与两个手杖合成，将手杖切换到破坏模式就能大大节省挖掘时间（手杖的破坏模式没有掉落物，谨慎使用）

回基地存物资，进主世界采几朵神秘花（在任务书找到植物魔法一章激活任务，并领取花肥）制作暮色传送门，进入暮色，使用指南针定位谜题羊树丛，使用魔法花肥收集16色神秘花做16色羊毛（羊毛可以从商店买）完成谜题羊解密，任务会给一些绿宝石币缓解金币紧缺。挖掘一些活根制作铁木锭，合成铁木块，使用瓦解号角转化为谜之金属块做盾牌基底，自此你在装甲上达到前期毕业。

输出与武器方面：武器使用前期给的新手小剑即可，武器材料可以从马玉灵，谜之金属，地岩信素，复合钢叶（可选）这几种材料中选取，建议的强化有德鲁伊之种，重伤（这个很好用，基本不会出现打不动带再生的boss，但是仙人掌与毒液瓶不好获取）

暮色boss攻略：路线建议先打牛头人迷宫和九头蛇，因为牛头人迷宫的宝藏房只要认领区块就随便摸并且能快速获得大量钢叶，九头蛇则是有抗火就能无伤。雪怪最好带上一桶水打断它的施法，否则会被高频攻击打死。暮色恶魂则建议酿造飞行药水击杀。打完三大boss后，就可以到巨魔洞窟的大黑曜石方块里拿余烬之灯，沃土以及魔豆，记得打死一个巨魔获取成就【恶作剧】以完成任务进度，到云上打死巨人会爆很多金币并且获取巨人剑。之后就是挖掘城堡砖（盾牌基底提供满血75%的强大减伤）和蓝色符文城堡砖通关暮色。

小技巧：

可以在暮色boss生成前使用恶念清除宝珠使boss只有基础等级和词条降低难度，也可以做成瓶装的在打完boss后饮用清除自身难度等级。模组带的灵魂出窍（alt+c）可以快速找到迷宫路线和幻影骑士墓。辉铋矿生成在暮色高原，不用打完三大boss解锁高原，在高原的可挖掘范围也可以挖到。

飞行药水如何获取：下届要塞的地狱疣，烈焰粉，狐狸小屋的酿药台，红色羊毛与安山合金制作小市场获得西瓜种子，成熟获取西瓜，紫菘果获取在科技一章，制作手摇曲柄解锁任务，制作工作盆，用工程师锤制作铁板做搅拌机即可领取，其他的金锭和萤石都能在商店获取

前期烧制物品：制作一个鼓风机和小水车即可大大加快烧制

关于循环物品：十分建议用5金币在亚马龙游商中购买修复护符。制作任意一个发电机与一个结晶器，获取火药 烈焰粉 岩浆块配合SDM商店即可做出琥珀结晶，制作丝织拖鞋免疫摔落伤害。如果有四个末影珍珠可以制作铭刻雷电法杖（下届合金在焦褐小屋有给）然后指南针搜索钢铁守卫者的结构就可以无伤过关（法杖放在副手右键，主手左键输出）

获取钢板（需要任意材质的劈刀在砧板剁钢铁守卫者的掉落物）随后在任务书特殊章 世界之外章节领取防火饰品。

高级工作台制作：大暮色橡树上有树洞获取暮色四树，并且树洞中刷蜘蛛，可以获取蜘蛛眼。暮色四树只出现在普通箱子而不是战利品箱子，获取树苗后在任务书可以领取它的匠魂产物。配合炽铁以及迷之金属即可制作

莱特兰恶意：魔能抢夺宝珠只需要一些铁木锭，火炬浆果，两个烈焰网，四个钻石块就能做出来。在任务书章节中通过抽取随机奖励可能抽出守卫者之眼，以制作本整合包公认轮椅武器——魂戈。

黑曜石-黑曜石青铜的组合在0.41a中由于其词条（往日种种，苦命鸳鸯）性质能作为前期优质输出，优点在数百点的暴力数值与小范围群攻让你不俱小怪，缺点在于触发间隔长，物伤且是反伤，打巫妖或者有再生词条的boss会极度乏力。
