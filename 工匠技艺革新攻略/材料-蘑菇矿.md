# 蘑菇矿（Shroomite）· 获取方式（CTI 0.43+）

> 结论（2026-10-13 核对整合包本体得出）：**蘑菇矿是 [TiT] 工匠巧思（Tinkers' Thinking）的三级匠魂材料，CTI 没有改它的任何配方**——
> `kubejs/` 与自制模组 `cti-1.2.2.jar` 里都搜不到蘑菇矿相关覆盖，只有材料数值被 CTI 调整过（见文末）。
> 所以照模组原生链做即可，整条链都是"采一株矿 + 两种材料"。

## 一、配方链（从原材料到工具部件）

```
丛林/竹林 浅层（y 0~40）挖 叶绿素矿石
        └─ 掉落 叶绿素A + 叶绿素B（时运加成；精准采集则掉原矿）

蘑菇矿混合物 =  叶绿素B ×1  +  诡异菌 ×1  +  荧光墨囊 ×1     （无序合成 → 1 个）
        └─ 高炉 100 tick（经验 1.2）→  蘑菇矿锭 ×1

蘑菇矿粒 ×9  →  蘑菇矿锭 ×1        蘑菇矿锭 ×9  ⇄  蘑菇矿块
蘑菇矿混合物 / 蘑菇矿锭  →  匠魂炉熔化 → 熔融蘑菇矿 90mb/锭（600℃）
        └─ 铸件台 + 锭铸模 → 蘑菇矿锭；铸造盆/铸件台 → 工具部件
```

要点：

1. **只有高炉（`minecraft:blasting`），没有普通熔炉配方**——`kubejs` 里没有覆盖，模组 jar 里也只有 `ingot_by_blasting.json`。MC百科的物品页把它标成"熔炉"，实际要进高炉（100 tick ≈ 5 秒）。
2. **叶绿素矿石没法种**：任务书原话"包里的叶绿矿没法种，挖一些够用了"。CTI 把它塞进 **丛林 / 竹林**（`minecraft:jungle`、`minecraft:bamboo_jungle`），垂直范围 **y=0~40**、每区块 **6 团**、每团最多 **6 个**，游戏内 tooltip 由 CTI 写成"常见于丛林浅层地下"。
3. **诡异菌**可以在 CTI 里用**热力 · 有机灌注机**增殖：`诡异菌 → 诡异菌（+1.31 概率额外一个）+ 6 诡异菌柄 + 9 诡异菌疣块`（水的消耗 1000、能量 60000）。没有这条配方就得去下界的诡异森林采。
4. **荧光墨囊**来自发光鱿鱼（原版掉落）。CTI 的 SDM 商店里**没有**蘑菇矿/荧光墨囊条目（已核对 `config/SDMShop/*.snbt`）。
5. 另有一条捷径：CTI 的**任务随机奖励表**里含 `蘑菇矿锭 ×3` / `蘑菇矿块 ×3`（`reward_tables/754C75D34C0D9CF9.snbt`、`3323AB18B55DB7F1.snbt`）。

## 二、蘑菇矿是什么定位

| 项目 | 数值 |
| --- | --- |
| 材料等级 | **三级**（`tier: 3`） |
| 头部 | 耐久 1050 · 挖掘等级 **钻石** · 攻击 2.75 · 挖掘速度 **30.0**（模组原始值 6.0，**CTI 上调到 30**） |
| 手柄 | 耐久 +15% · 攻速 −0.1 · 伤害 +0.05 |
| 镶板盔甲 | 头盔 2.5 甲/363 耐久 · 胸甲 6.5 甲/528 · 靴子 2.5 甲/429 · 韧性 0.5 |
| 特性 | **shady**（近战/采掘、远程）：天空亮度越低挖掘越快；**shadowing**（盔甲、盾牌基底） |

所以它是一把**"暗处挖得快"的钻石级挖掘头**；任务书里那条任务的副标题就是"天空亮度越低挖掘越快"。
