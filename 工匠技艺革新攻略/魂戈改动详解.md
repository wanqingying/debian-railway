# 魂戈改动详解（0.43 → 0.46）

> 数据源：MC百科更新日志（0.43 = 2026-05-31，0.46 = 2026-10-01）+ 整合包本体 `dreamforSh/CTI-server`（`kubejs/server_scripts/cti.js` 标注版本 0.46）里的工具定义、强化配方与语言文件。
> 魂戈 = **`solidarytinker:soulge`**（Solidary Tinker / 「ST(CTI特供)」1.1.4）。

---

## 一、它是什么

**部件与倍率**（`kubejs/data/solidarytinker/tinkering/tool_definitions/soulge.json`，CTI 覆盖了模组默认值）：

| 部件 | 权重 |
| --- | --- |
| 小剑刃 | 0.25 |
| **魂珠**（`soulge_heart`） | 1 |
| 小剑刃 | 0.25 |
| 宽剑刃 | 0.5 |
| 坚韧手柄 | 1（手柄倍率） |

基础面板：攻击伤害 1、攻击速度 1.0，三个倍率（攻速/攻击/耐久）**统一 1.0**。
基础槽位：**能力槽 1、升级槽 2**。
默认特性：**棱镜变换（`anymoremode`）**——单头 / 多头模式的切换菜单。

**两种形态**（模组原文）：

- **多头模式**：可标记目标，攻击范围内最多标记 11 名敌人，右键自动索敌。
- **单头模式**：只能打一个目标；持续攻击 2 秒后升温（1.05 倍），6 秒进入二档（1.5 倍）；失去目标 0.5 秒后降温回最低档。

## 二、时间线

### 0.43（2026-05-31）—— 削面板、砍频率、重做攻速转换

| 日志条目 | 改了什么 | 玩家影响 |
| --- | --- | --- |
| `30` | **降低魂戈基础面板倍率**，材料倍率改为标准的 1 | 就是上面那张表：三个倍率 1.0、宽剑刃 0.5、小剑刃各 0.25 |
| `5` | 大部分魂珠攻击频率**下调，最高 3**，同时新增几个加频率的专属强化 | 频率成了稀缺属性 |
| `69` | 魂珠**基底**由守卫者之眼 → **守卫者符文**，需天境击败滑行魔石才解锁 | 获取门槛抬到天境 |
| `88` | 下调加力燃烧的燃烧倍率 | 燃料流削弱 |
| `89` | 单头模式**换挡所需的时长增加**、冷却也增加；一次加温可持续 2 秒，2 秒内持续攻击可续火 | 单头节奏变慢 |
| `90` | 增加魂戈燃料的 JEI | 纯体验 |
| `100` | 新增**抖杖术**：+30% 攻击频率、**−220% 攻击伤害**，主手再 −20% 受治疗 | 极端频率流 |
| `101` | **重构攻速转换**：不再直接乘，改为按攻击频率换算，攻速识别上限 10 | 攻速收益被压平 |
| `87` | 修复单头模式超载燃烧消耗流体倍率异常 | bug |

### 0.46（2026-10-01）—— 拆能力、改公式、放宽获取

| 日志条目 | 改了什么 | 玩家影响 |
| --- | --- | --- |
| `工具 5` | **魂珠配方大幅降低**（4 任意肉 + 1 蜘蛛眼）；但魂戈**默认不再带斩杀**、**不能切换单头**、**不能穿墙索敌**；几乎所有魂珠默认攻击频率再降 | 武器白板化，能力变成要装的强化 |
| `工具 6` | 攻速超过 1 **不再无脑转伤害**，改为按攻击频率增伤/减伤，攻速识别上限 10（原文给两例：频率 2 + 攻速 10 = 1.0 倍；频率 1 + 攻速 10 = 0.5 倍） | 公式见下一节 |
| `工具 7` | 新增 **8 个专属强化**：独立攻击频率乘区、多头斩杀、开放单头、穿墙、额外抢夺、额外掉落（固定 7 倍）等，每个还附赠频率/面板/抢夺/增伤 | 能力回来了，但要占槽位与材料 |
| `工具 8` | 单头模式**冷却时长延长**，高温可多维持 **8 tick** | 单头续航略好 |
| `材料 128` | （同版本背景）星界龙陨石倍率 32500% → 1200% 等 | 与魂戈无关，但同属武器层大砍 |

**一句话总结**：0.43 把魂戈的「数值」压平（面板倍率、频率、攻速转换），0.46 把魂戈的「能力」拆开卖——**白板 + 8 个可装配强化**，同时把魂珠的价格打到白菜。

## 三、伤害怎么算：单头与多头是两套公式

源码位置：`solidarytinker` 的 `Modifiers/Tool/Soulge/AnymoreMode.getMeleeDamage`（公开仓库 `lovelyFirefly/solidarytinker` 的 `AnymoreMode.java` 结构一致；1.1.4 的字节码常量也对得上：`1.15 / 1.35 / 1.5 / 2.5 / 10.0 / 20.0`）。

```java
// 多头
倍率 = min(攻速, 10) × 攻击频率 ÷ 20          // 攻速按 10 封顶
// 单头
倍率 = 温度档 × 燃料倍率 × √(超载倍率)         // 完全不乘攻速
```

**多头**：

- 每次命中 = 武器伤害 × 上式；同时打所有被标记目标（最多 11 个），每次消耗 1 点耐久。
- 攻速 10 + 频率 2 = **1.0 倍**；频率 3 = **1.5 倍**；攻速低时衰减很快（攻速 4 + 频率 1 = 0.2 倍）。
- 装了魂归忘忧才会斩杀（按魂珠的斩杀线）。

**单头**：

- 温度档（持续攻击时每 5 tick 累加 1 点温度）：
  - 0–3 秒（≤12 点）：**×1.0**
  - 3–5 秒（13–20 点）：**×1.15**
  - 5 秒以上（>20 点）：**×1.35**
- 装了**加力燃烧**、罐里有正确燃料且 ≥10mB：
  - 3–5 秒：**×1.5**
  - 5 秒以上：**×2.5**
  - 再乘**燃料倍率**（0.8 / 1.1 / 1.2 / 1.5 / 1.8 / 2.5 / 3.5，视燃料而定）
  - 装了**超载燃烧**再乘 **√(燃烧倍率)**（燃烧倍率最高 25 → 最多 ×5）
- 停手约 3 秒（冷却 12×5 tick）温度清零；0.46 把高温维持时间又延长了 8 tick。
- **单头不触发斩杀**，且只能打一个目标。

**谁更高？**

| 场景 | 单头 | 多头 | 结论 |
| --- | --- | --- | --- |
| 白板（无燃料） | ×1.0 → ×1.15 → ×1.35 | ×0.1 ~ ×1.5（看攻速与频率） | 攻速/频率堆满时**多头更高** |
| 加力燃烧 + 好燃料 | ×1.5 / ×2.5 × 燃料倍率 | 同上 | 单头开始反超 |
| 加力燃烧 + 超载燃烧 + 3.5 倍燃料 | 2.5 × 3.5 × 5 ≈ **×43.75** | ≤ ×1.5 | **单头碾压**，但占两个能力槽、耗燃料、无斩杀、单体 |

换句话说：**单头是「燃料换上限」的塔模式，只有把燃料流堆满才比多头高**；日常刷怪、打钱、群怪，多头更划算（还能斩杀）。

## 四、8 个专属强化（当前版本可装的实现）

槽位：**魂戈只有 1 个能力槽 + 2 个升级槽**——8 个里 7 个是 **ability**，只有 1 个是 **upgrade**。所以**不可能全带**，必须取舍（要全带得靠额外加槽的强化/创造槽）。

| 强化 | 名称 | 槽位 | 效果（模组原文要点） | 配方（本包 0.46） |
| --- | --- | --- | --- | --- |
| `soulback` | **魂归忘忧** | 升级 | 按「斩杀线」属性在攻击时斩杀目标；抢夺 +2；攻击间隔 −20% | 幽匿脉络 ×5 + 幽魂质 ×1 + 幽匿脉络 ×5 + 幽灵锭 ×16 + 魂金锭 ×16 |
| `zywooplay` | **真视之眼** | 能力 | 可**隔墙攻击**；+30% 最终攻速；+25% 最终攻击伤害 | 虚空之眼 ×5 + 星云之眼 ×1 + 虚空之眼 ×5 + 虚空结晶锭 ×8 ×2 |
| `reality_ruler` | **支配者** | 能力 | 攻击间隔 −35%；主手击杀时**掉落物 ×7**；抢夺 +8；+45% 面板攻击 | 黑石核心 ×3 + 虚空珍珠 ×1 + 基岩合金锭 ×6 + 遗忆锭 ×3 + 龙霜钢锭 ×2 |
| `inferno_core` | **炼狱核心** | 能力 | 按键配置**切换单头塔模式**；持续攻击伤害递增但**不能斩杀、不能多目标**；二档 1.15、三档 1.35；攻击间隔 −10% | 炽铁锭 ×2 + 地狱戈伯玻璃 ×3 |
| `extraburn` | **加力燃烧** | 能力 | 仅单头：+40000mB 燃料容量；有燃料时基础变档倍率升到 1.2 / 2.5；总伤害再 × 燃料倍率 | 不稳定酶腺 ×8 + 焦黑储罐 ×1 + 不稳定流体 ×32 + 炽铁锭 ×8 + 磨制玫瑰石英 ×16 |
| `overloadburn` | **超载燃烧** | 能力 | 开放额外燃烧倍率（最多 +25 倍）；燃烧效率的平方根转为**独立伤害乘区** | 灵浆水晶 ×25 + 永燃水晶 ×10 + 烈焰水晶 ×25 + 超低温钢锭 ×16 ×2 |
| `tremblestaff` | **抖杖术** | 能力 | +30% 攻击频率；**−220% 攻击伤害**；主手 −20% 受治疗 | 摩赛特块 ×4 + 速度升级 ×64 + 玛迪特锭 ×6 + 地岩信素锭 ×5 + 喋血锭 ×7 |
| `anymoremode` | **棱镜变换** | 默认特性 | 打开按键界面切换单头/多头 | 自带（不是配方） |

补充：**扼杀（`crawl`）** 会在即将斩杀时把目标抓到身前斩杀；它不在 0.46 的「8 个」之列，但同样只对魂戈生效。

## 五、现在怎么玩（三套配置）

前提：1 个能力槽。要么选一套，要么先加槽。

1. **刷怪/打钱流（推荐）**：能力 **支配者**（掉落 ×7、抢夺 +8、攻速 −35%）+ 升级 **魂归忘忧**（斩杀 + 抢夺 +2、攻速 −20%）。
   攻速被两个强化各减一截，正好抵消 0.46 倍率公式里「攻速 = 分子」的收益；掉落 7 倍是纯收益。
2. **单体爆发流**：能力 **炼狱核心** + 燃料（加力燃烧/超载燃烧只能二选一，都在能力槽），走单头塔叠档；配合 0.46「高温多维持 8 tick」，站桩输出最稳。注意单头**不能斩杀**、只能打一个目标。
3. **穿墙/风筝流**：能力 **真视之眼**（隔墙 + 30% 攻速 + 25% 伤害），配合渎神/突破/放血三条扣血换攻速的词条，把攻速顶到 10，再用高频率魂珠把倍率推到 1.5。

**共同注意**：

- 0.46 之后**白板魂戈没有斩杀**——想要斩杀必须装「魂归忘忧」（升级槽），这是最优先的一件。
- 魂珠现在很便宜（4 肉 + 1 蜘蛛眼 + 5 锭，铸模消耗），**可以多备几颗不同频率的**：高频率配攻速流，低频率配单头流。
- 单头模式的「升温」是时间换伤害：2 秒 1.05、6 秒 1.5，配合炼狱核心的二/三档（1.15/1.35）叠起来才明显。
