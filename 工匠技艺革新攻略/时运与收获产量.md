# 工匠：技艺革新 · 时运（附魔工具）与收获产量

> 回答的问题：**收获作物时，附魔工具能提高产量吗？**
> 结论先说：**能，但由「作物自己」决定**——每个方块有自己的掉落表，掉落表里声明了 `minecraft:fortune` 才吃时运；没声明的，时运再高也没用。原版与包内作物都不是一刀切，实测（下面全部来自本包文件的掉落表）大致是「**一半吃、一半只吃种子、一小撮完全不吃**」。
>
> 证据来源：整合包本体 `dreamforSh/CTI-server`（快照 2026-10-02）里 251 个模组的**方块掉落表**（扫出全包 7815 张方块掉落表，其中 318 张含 `minecraft:apply_bonus` + `minecraft:fortune`）；原版作物对照 `misode/mcmeta` 的 1.19.2 官方数据。复现命令见文末。

---

## 一、机制：为什么"看作物"

时运（Fortune）不是一个全局倍率，而是一个**掉落表函数**。收获时游戏用「你手里那把工具」建一个掉落上下文，掉落表里的：

- `binomial_with_bonus_count`（`extra 3, probability 4/7`）：每级时运 = 多项分布多投 3 次 → 平均 **+1.71 个/级**（原版小麦种子、胡萝卜、马铃薯、本包多数作物用这个）
- `uniform_bonus_count`（`bonusMultiplier 1`）：每级时运 = 上限 +1 → 平均 **+0.5 个/级**（西瓜片、甜浆果、浆果丛）
- `uniform_bonus_count`（`bonusMultiplier 2`）：**每级 +2 上限**（包里的"野生"作物：野生胡萝卜/马铃薯/甜菜根、洞窟胡萝卜）

所以问"能不能增产"必须一层层问：**① 这个作物吃不吃时运 → ② 我手上工具的时运等级是多少**。

**工具侧**：原版附魔适性里 Fortune 可用于 **镐 / 斧 / 锹 / 锄**（`primaryitems`，也就能用附魔书+铁砧打上去）。收作物不需要正确工具，**你手上那一把**的时运等级就算数——拿时运锄挖胡萝卜会多，拿空手挖就不会。

### ❌ 完全不吃时运

原版 **南瓜 / 甘蔗 / 可可豆（固定 3） / 竹子 / 海带 / 发光浆果 / 紫颂花**；
农夫乐事 **水稻**（`rice_panicles`：整张表没有时运函数，且**必须用刀**才有稻米，否则掉稻穗）；
暮色森林 **火炬浆果**（`torchberry_plant`：固定 1 个，精准采集/剪刀才拿植株）。

> 顺带一个"任务书说错了"的例子：暮色任务书那条写着「更多的**能吃时运**的火炬浆果植物（？）」——作者自己都打了个问号，实测掉落表里没有时运函数，**不增产**。

## 三、怎么把时运装到工具上（本包可行路径）

| 路径 | 说明 |
| --- | --- |
| 原版附魔 | 时运书 → 附魔台/铁砧上 **镐/斧/锹/锄**；收作物时手持哪把算哪把 |
| **匠魂「幸运强化」（`tconstruct:luck`）** | 匠魂3 把**时运与抢夺合二为一**。数据文件 `data/tconstruct/tinkering/modifiers/luck.json` 里它是 `constant_enchantment: minecraft:fortune`，每级 +1 时运，作用于 `tconstruct:modifiable/harvest` 工具——**就是真时运等级**，会作用到作物掉落表上 |
| **匠魂「收割」（`tconstruct:harvest`）** | 工具描述：「工具可收割并重新种植农作物」。**短刃镰（`tconstruct:scythe`）**、**宽刃镰（`tinkers_ingenuity:bigsickle`）** 就是任务书推荐的收割工具；掉落走掉落上下文（含"收割附魔"钩子），配幸运强化即吃时运 |
| CTI 自制工具 | 任务书：开拓者系列「**初始自带 2 级时运**」；紫晶石强化「增加时运和百分比属性增幅」，即**匠魂工具也能自己堆时运等级** |
| 热力·灌注机（bottler） | 包内改过的配方：**下界合金镐 + 石油醚 → 时运 5**；+ 记忆精华 → 时运 3；AE 歼灭面板 → 时运 3（`kubejs/server_scripts/thermal.js`） |
| 循环 **园艺镰**（`cyclic:scythe_harvest`） | 「范围收割」，说明与循环收割机同逻辑；作为普通工具可附时运（本模组的"自动冶炼"附魔说明写着与时运/精准采集互斥） |
| **工业先锋「时运插件」** | 机器自动化路线：插件自身需要附魔**时运**，其等级决定机器行为时的等级，为能接收它的机器提供"时运/掠夺"——即**机器也能吃时运**，配种植机/采集机做全自动农场 |
| 七咒之戒 / 贡献者彩蛋等 | 任务书提到"很长时间不死亡 → 所受伤害减少并**时运与抢夺增加**"（七咒之戒的奖励面） |

## 四、四条容易踩的坑

1. **别用小刀/镰刀去收小麦期待翻倍**：小麦本体固定 1，时运只加种子。热力农业、多元乐事、农夫乐事卷心菜同理。
2. **想要作物本体翻倍，优先种**：原版胡萝卜/马铃薯、西瓜、下界疣、甜浆果、农夫乐事洋葱/番茄、额外乐事玉米/姜、热力霜瓜与四种菇、天境浆果、地下花园浆果、循环苹果芽。
3. **农夫乐事水稻要用刀**（`farmersdelight:tools/knives` 标签）才有稻米，而且它不吃时运——要产量就得多栽。
4. **精准采集**只在掉落表声明了 silk touch 分支的地方生效（原版西瓜→整块西瓜）；多数模组作物没有这一支，附精准采集等于浪费附魔位。

## 五、复现命令（本机可直接跑）

```bash
cd /tmp/opencode/CTI-server   # 整合包本体仓库快照
# 1) 扫全包：哪些方块掉落表吃时运
W=/tmp/opencode/lootscan; rm -rf $W && mkdir -p $W/work
for jar in mods/*.jar; do
  unzip -q -o "$jar" 'data/*/loot_tables/blocks/*.json' -d $W/work 2>/dev/null
  find $W/work -name '*.json' -exec grep -l '"minecraft:fortune"' {} \; \
    | sed "s|$W/work/||" | sed "s|^|$(basename $jar)\t|" >> $W/fortune.txt
  rm -rf $W/work/*
done
grep -iE 'crop|seed|berr|rice|tomato|corn|tea|coffee' $W/fortune.txt   # 只看作物类

# 2) 看单个作物到底怎么算
unzip -p mods/thermal_cultivation-1.19.2-10.3.0.19.jar data/thermal/loot_tables/blocks/rice.json

# 3) 匠魂幸运强化的定义（= minecraft:fortune）
unzip -p mods/TConstruct-1.19.2-3.8.5.58.jar data/tconstruct/tinkering/modifiers/luck.json
```

原版对照（1.19.2 官方数据）：`https://raw.githubusercontent.com/misode/mcmeta/1.19.2-data/data/minecraft/loot_tables/blocks/<方块>.json`（如 `carrots.json`、`beetroots.json`、`melon.json`）。
