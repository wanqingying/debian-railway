# 工匠：技艺革新 · 远程武器伤害看材料的哪个属性

> ⚠️ **后续更正（2026-10-14，见 `远程武器材料推荐.md` §0）**：下面 §1 引的「初速度是箭矢伤害乘数」是**匠魂3 原版**机制。**CTI 已经关掉这个乘数**——任务书《远程材料》原话「箭矢伤害不再受到速度增幅」，`cti-1.2.2.jar` 里也有 `AbstractArrowMixin` 接管箭矢伤害。面板公式（§1 的初速度算法、§4 的三例验证）依然成立，**但初速度在本包不再放大伤害**；本包远程伤害几乎全靠强化（力量等）与材料词条。
>
> 回答的问题：**匠魂的远程武器（长弓、回旋镖/手里剑、弩）的伤害，是根据材料的哪个属性？**
> 结论：**材料里唯一影响远程伤害的是「初速度」（`tconstruct:velocity`），它来自弓臂或刀刃部件的材料属性，并且对伤害是乘算放大**；另一个面板值「弹射物力量」（`tconstruct:projectile_damage`）**不来自材料**，来自强化（力量、晶固、钻石等）。弓把只影响近战伤害、精确度与耐久，**不影响射击伤害**。
>
> 证据：官方文档与源码 + MC百科算法贴 + 整合包本体的材料数据与任务书成品面板（三方对得上，见 §4）。

---

## 1. 远程武器的四个独有面板值

| 面板 | 英文 / 数据键 | 含义（官方描述） |
| --- | --- | --- |
| 初速度 | velocity / `tconstruct:velocity` | 「决定发射后箭矢的飞行速度。**箭矢的速度越快，其造成的伤害越高**」——官方文档补一句：它「不只是速度，**也是箭矢伤害的乘数**」 |
| 拉弓速度 | draw speed / `tconstruct:draw_speed` | 决定这把弓每秒能使用的次数（回旋镖/吹箭筒决定**攻击间隔**） |
| 弹射物力量 | projectile power / `tconstruct:projectile_damage` | 弹射物的**基础伤害**。源码注释：「假设箭本身有 2 点伤害，我们在这之上加成」 |
| 精确度 | accuracy / `tconstruct:accuracy` | 决定瞄准点距中心的距离（默认 0.75，上限 1） |

**公式**（MC百科《匠魂3各工具的统计数据及其算法详解》+ 官方源码默认值）：

```
初速度        = (1 + Σ 部件权重 × 材料初速度) × 工具初速度倍率      # 默认基数 1
发射后初速度  = 0.15 × 面板初速度  (格/刻)
弹射物基础伤害 = 弹射物原基础伤害(箭=2) + (面板弹射物力量 − 2)      # 弹射物力量默认 2
伤害 ∝ 初速度   # 乘算放大
```

- **长弓的两条弓臂数值全额相加**（不像其它多顶端工具取加权平均）；**回旋镖的四个刀刃按 0.5、0.5、1、1 的权重相加**（前两片只有一半权重，见 `tool_definitions/shuriken.json` 的 `scale: 0.5`）。

## 2. 长弓的部件分工

长弓 = 弓臂 ×2 + 弓把 + 弓弦（`data/tconstruct/tinkering/tool_definitions/longbow.json`）。

| 部件 | 统计类型 | 提供的属性 | 影响射击伤害 |
| --- | --- | --- | --- |
| 弓臂 | `tconstruct:limb`（弓臂） | 耐久、拉弓速度、**初速度**、精确度 | **是**（初速度乘算） |
| 弓把 | `tconstruct:grip`（弓把） | 耐久倍率、精确度、**近战伤害** | 否（只在近战敲击时生效） |
| 弓弦 | `tconstruct:bowstring`（弓弦） | 只有材料词条（如抢夺） | 否 |

## 3. 回旋镖 / 手里剑

- CTI 里的回旋镖 = **`tinkers_ingenuity:shuriken`**（匠心之作 2.0.8），**4 个刀刃部件**，是**远程武器**（任务书原话：「不同于 1.12 的回旋镖，整合包中的回旋镖是远程武器而非近战武器」）。
- 它的刀刃在数值上用的是**弓臂那一套统计**（初速度 / 拉弓速度 / 精确度 / 耐久），不是顶端攻击力 —— 计算验证见 §4 第三行。
- 工具自带**初速度倍率**：回旋镖 0.82（吹箭筒更低，所以任务书说「回旋镖有 4 个部件、略低的基础初速度、更高的初速度倍率」）。
- ⚠️ 网上常见的「回旋镖伤害 = 2 + 攻击力 × 0.7，攻击力取 4 刀刃攻击力平均值」是**匠魂2（1.12）**的公式，不适用于 TiC3 + 匠心之作；本包任务书明确说它的定位是远程武器。

## 4. 实测验证（用整合包任务书里的成品面板反推）

材料全部为 `etshtinker:exo_alloy`，它的**弓臂初速度 = 1.5**（包内 `data/etshtinker/tinkering/materials/stats/exo_alloy.json`）。

| 武器 | 部件 | 面板初速度 | 按公式预测 | 面板弹射物力量 |
| --- | --- | --- | --- | --- |
| 长弓 | 弓臂 ×2 + 弓把 + 弦 | **4.00** | 1 + 1.5 + 1.5 = **4.00** ✓ | 38.410526 |
| 重弩（匠心之作） | 弓臂 ×1 + 弦 | **2.50** | 1 + 1.5 = **2.50** ✓ | 38.410526 |
| 回旋镖（匠心之作） | 刀刃 ×4（0.5/0.5/1/1） | **4.51** | (1 + 3 × 1.5) × 0.82 = **4.51** ✓ | 38.410526 |

三点结论：

1. 「初速度 = 1 + Σ 权重 × 材料初速度」三例**全部精确命中**（4.00 / 2.50 / 4.51）。
2. 回旋镖若按「顶端攻击力」算应该是 (1 + 3×4.75) = 15.25，与实际 4.51 不符 → **刀刃用的确实是弓臂(limb)统计**。
3. 三把武器的**弹射物力量完全相同（38.410526）**，而它们的材料与部件数不同 → 这个面板值**完全来自强化与材料特性**，与材料属性无关。

## 5. 「弹射物力量」从哪来（强化/特性清单）

| 来源 | 效果 | 类型 |
| --- | --- | --- |
| **力量**（Power，`data/tconstruct/tinkering/modifiers/power.json`） | 每级 +0.5 弹射物力量（1.20.1 之后第 1 级再 +1） | 远程升级 |
| **晶固**（紫水晶青铜/紫水晶） | 每级 +0.1 初速度、+0.75 弹射物力量，同时限制出射角 | 材料特性 |
| **钻石** | 提高弹射物伤害 | 升级强化 |
| **弓狙**（紫水晶/燧石/铜强化远程器械） | 每级 +0.2 精确度、+1.2 攻击伤害 | 材料特性 |
| **精致**（匠心之作） | 每级 +1.2 近战伤害与弹射物伤害 | 材料特性 |
| **投射**（Ballista）能力 | 长弓可发射近程工具，伤害按「工具基础伤害 × 工具初速度」计算 | 远程能力 |

| 参考：匠魂3 原版**钢** | +0.2 | −0.3 | −0.1 | 775 |

也就是说 CTI 把「初速度」这一项数值放大了两个数量级；在 CTI 里追远程伤害，弓臂材料几乎只看这一列的排名。

**挑选口诀**：想打**单体高伤** → 堆初速度（上表）+ 力量；想打**高 DPS** → 优先拉弓速度（但要备足弹药）；想**打得准** → 精确度。弓把随便挑耐久与词条好的，反正不影响射击伤害。

## 7. 复现命令

```bash
cd /tmp/opencode/CTI-server          # 整合包本体快照（mods/ + kubejs/ + config/ftbquests/）
# 长弓的部件与统计映射
unzip -p mods/TConstruct-1.19.2-3.8.5.58.jar data/tconstruct/tinkering/tool_definitions/longbow.json
# 回旋镖的部件与权重（0.5 / 0.5 / 1 / 1）与初速度倍率 0.82
unzip -p mods/tinkers_ingenuity-2.0.8.jar data/tinkers_ingenuity/tinkering/tool_definitions/shuriken.json
# 材料数值（弓臂 = tconstruct:limb）
unzip -p mods/etshtinker-2.0.3.jar data/etshtinker/tinkering/materials/stats/exo_alloy.json
# 任务书里的成品面板（tic_materials + tic_stats）
grep -n "tconstruct:longbow\|tinkers_ingenuity:shuriken\|tinkers_ingenuity:heavy_crossbow" \
  config/ftbquests/quests/chapters/toolcollection.snbt
# 力量强化的数值
unzip -p mods/TConstruct-1.19.2-3.8.5.58.jar data/tconstruct/tinkering/modifiers/power.json
```

全包弓臂初速度排名脚本（本次使用）：`/tmp/opencode/limbrank.mjs`。
