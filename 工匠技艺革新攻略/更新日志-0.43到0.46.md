# CTI 更新日志整理：0.43 → 0.46

> 数据源：MC百科《[CTI]工匠：技艺革新》更新日志 <https://www.mcmod.cn/modpack/version/989.html>
> 0.43 = 2026-05-31，0.46 = 2026-10-01。**百科没有 0.44 / 0.45 的日志条目**（版本页的版本流是 0.43 → 0.46，0.44/0.45 未在百科建条目），所以「0.43 到 0.46」实际只有这两条日志，共 483 条。

分类口径：
- **改动**：新增/重做/更名/等级与温度/配方与产出途径/删除整件内容/性能与体验
- **加强**：既有东西变强（面板、数值、效果、掉落率）
- **削弱**：既有东西变弱（数值下调、能力/词条/机制被移除）
- **修复**：bug 修复

## 重点变化（人工提炼）

**0.46（2026-10-01，316 条，一次大版本）**

- **两条新流派**：魔力脉冲（消耗魔力打远程近战，`材料 20`）、灼伤（DOT 核心，`材料 32`），并连带重做了魔力钢 / 泰拉钢 / 盖亚魂 / 焦褐石 / 烈焰骨 / 红宝石等一整套材料。
- **科技侧补新料**：塑钢锭（5 级，前期叠伤，`材料 49`）、钛晶锭（费罗锭更名，6 级生命拐，`材料 110`）、工业胶质（`材料 29`）。
- **生命/护盾系大扩张**：玛丽锭（`材料 71`）、异变（`52`）、狂傲之徒 I/II/III（`65`）、躯体化恶魔（`120`）、黎明使者（`67`）、无终恨意（`66`）。
- **魂戈体系重做**：默认不再带斩杀 / 不能穿墙索敌 / 攻速超 1 不再无脑转伤害，同时新增 8 个专属强化补回能力（`工具 5、6、7`）。
- **星界龙大砍**：陨石额外伤害 32500% → 1200%，易伤 3300% → 900%，边缘触碰 1000% → 350%（`材料 128`），每级攻击 1000 → 850（`132`）。
- **删内容**：血神锭（`136`）、短弓（`工具 4`）、无线收发器配方（`科技 15`）、生来之恶/重装等旧强化。
- **弹射物不再吃初速度**（`杂项 12`）—— 与「远程武器看初速度」的旧结论相反，本包远程彻底改为吃强化与词条。
- **七咒新增诅咒**：玩家默认不能击退怪物（`冒险 66`）。

**0.43（2026-05-31，167 条）**

- **匠魂炉增产统一**：原矿 3 倍、碎矿 2 倍、精炼炉最多 6 倍（`59`），并给矿脉/副产物大改（`58、61、63、68`）。
- **熔岩筛矿大砍**：熔岩产出大幅下调、炉渣产物概率压到 5%~30%、加工温度上调（`65`）。
- **移除 Mek 非终极工厂配方**（`64`）、移除千咒卷轴（`70`）、移除生来之恶与重装强化（`124、142`）。
- **新武器**：感知刺剑（利刃华尔兹 + 词缀系统，`126`）；**新玩法材料**：未花锭（8 级，`91`）、玛丽锭（`92`）。
- **星野锭配方改为冒险 + 科技双毕业**，与极寒彩钢一起升到 8 级（`11`）。
- **魂戈攻速重做**（`101`）、经验钢阈值 1 级 5000 并加遗者（`99`）、AE 集魔接口（`38`）。
